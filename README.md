# TS30013 Breakout Board
This is a breakout board for the TS30013 switching voltage regulator, produced by Semtech Corporation.
This board takes in from 4.5VDC to 18VDC input and puts out 3.3VDC; additionally, it can supply up to 3A of current.
This board provides several male and female pins, as well as a screw terminal block, through which to access the power output.
